# Cânticos – Outubro Missionário 2.1

Aplicativo Android offline para visualizar letras e cifras com navegação rápida.

## Recursos
- Importação de novas músicas em PDF pelo seletor de arquivos do Android.
- Extração automática do texto de cada página do PDF com PDFBox Android.
- Editor de música antes/depois da importação.
- Ajuste da posição das cifras usando deslocamento de 1 ou 4 espaços para esquerda/direita.
- Criação e edição de listas personalizadas/repertórios.
- Modo de navegação apenas pelas músicas da lista ativa.
- As músicas originais continuam incorporadas ao app.
- Dados importados, ajustes e listas ficam salvos localmente no aparelho.

## Lista padrão incluída
A versão 2.1 cria automaticamente a lista **“Missa Mês Missionário Santa Casa”** com todas as músicas originais fornecidas no PDF-base.

Compatibilidade mínima: Android 6.0 (API 23).
